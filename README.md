# Credit Risk Modeling Using Machine Learning

An end-to-end credit risk classification project built on the **German
Credit Risk** dataset. The project moves through exploratory data analysis,
feature engineering, model training and tuning, and a Streamlit web app for
serving predictions.

## Project Structure

```
.
├── credit_risk_modeling.ipynb   # Full analysis, feature engineering & modeling notebook
├── app.py                       # Streamlit prediction app
├── requirements.txt             # Python dependencies
├── german_credit_data.csv       # Dataset (not included - see about the Data below)
└── *.pickle                     # Exported model + encoders (generated by the notebook)
```

## Step-by-Step Implementation

1. **Setup & Imports** - pandas, numpy, matplotlib, seaborn.
2. **Load the Dataset** - read `german_credit_data.csv`.
3. **Initial Cleaning** - drop the redundant index column, drop rows with
   missing `Saving accounts` / `Checking account` values, check for
   duplicates.
4. **Univariate Analysis** - histograms and boxplots for numeric features
   (`Age`, `Credit amount`, `Duration`); count plots for categorical
   features (`Sex`, `Job`, `Housing`, `Saving accounts`, `Checking account`,
   `Purpose`).
5. **Bivariate Analysis & Correlations** - correlation heatmap, grouped
   means by `Job` and `Sex`, a pivot table of credit amount by
   `Housing`/`Purpose`, a scatter plot of age vs. credit amount, and a
   violin plot of credit amount by saving accounts.
6. **Risk-Focused Analysis** - class balance of the `Risk` target, and how
   each feature varies across `good` vs. `bad` risk labels.
7. **Feature Engineering** - select modeling features, label-encode
   categorical columns and the target, and export the encoders with
   `joblib`.
8. **Train/Test Split** - 80/20 stratified split (no scaling needed, since
   every candidate model is tree-based).
9. **Model Training & Tuning** - `GridSearchCV` (5-fold, accuracy-scored)
   over four tree-based classifiers:
   - Decision Tree
   - Random Forest
   - Extra Trees
   - XGBoost
10. **Model Comparison** - compare test accuracy across all four models and
    select the best performer.
11. **Export** - persist the winning model with `joblib`.
12. **Streamlit App** - `app.py` loads the model and encoders, collects
    applicant details through input widgets, and returns a **Good** /
    **Bad** risk prediction.

## Requirements

```bash
pip install -r requirements.txt
```

## Data

This project expects `german_credit_data.csv` in the project root. It is the German Credit Risk dataset, distributed via Kaggle, with the following columns:

`index, Age, Sex, Job, Housing, Saving accounts, Checking account, Credit amount, Duration, Purpose, Risk`

## Usage

1. Place `german_credit_data.csv` in the project root.
2. Run `credit_risk_modeling.ipynb` end to end. This generates the encoder
   pickles and `credit_risk_model.pickle`.
3. Launch the app:

   ```bash
   streamlit run app.py
   ```
4. Open the local URL Streamlit prints in the terminal, fill in applicant
   details, and click **Predict Risk**.
